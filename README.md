# Rednotes-English · 看美剧学地道口语

一个基于 [Obsidian](https://obsidian.md) 的个人英语学习库，围绕美剧 **老友记（Friends）** 全 10 季，把「精看剧集 → 提炼知识 → 输出检验」串成一个完整闭环。所有笔记以中文讲解、双链（`[[...]]`）互联，可直接用 Obsidian 打开使用。

> 学习理念：**输入素材 → 知识沉淀 → 输出去检验**。每天精看一集，提炼生词/句型/语法，每周做一次输出练习。

## 🚀 快速开始

1. 用 Obsidian「打开文件夹作为仓库」，选择本目录。
2. 从 **[[English-Home]]**（`99-MOC/English-Home.md`）进入总导航。
3. 想学某一集，进 **[[Friends-Index]]** 找到对应集数的学习笔记。
4. 复习词汇/句型/语法，分别查阅 `02-Vocabulary/`、`04-Phrases/`、`03-Grammar/`。

## 📚 各模块说明

### 01-Show · 剧集学习笔记

每集一份笔记（`Friends.S0xE0y_地道口语学习笔记.md`），结构固定：

- **高频缩略与口头禅**：`sec / gonna / wanna` 等必背连读缩略
- **地道短语与习语**：如 `steal sb's thunder`、`hold down the fort`
- **万能口语句型**：可举一反三的句式
- **精彩比喻与幽默台词**：可模仿的英文表达
- **本集彩蛋**：值得复述的对话小片段

原文中的地道表达用 `==高亮==` 标记，附中文翻译与语境「点拨」。

### 02-Vocabulary · 高频词汇

每季一份，按 **8 大主题**分类：人物关系 / 情感状态 / 生活场景 / 俚语粗话 / 职场 / 医疗身体 / 文化娱乐 / 通用高频动词短语。每个词条标注词性、释义、出现集数与例句，`[ ]` 复选框可勾选表示已复习。

### 03-Grammar · 语法专题

从全剧提炼的语法点，反向链接回来源剧集：

- **口语时态与语气**（170 点）：时态切换、现在完成时、虚拟语气/条件句、情态动词、关系从句、嵌入式问句等
- **口语句式与修辞**（167 点）：倒装、反意疑问、伪分裂/强调句、排比重复、反语、明喻暗喻、双关等
- **口语缩略**：`gotta / wanna / gonna` 连读专题

### 04-Phrases · 口语句型仓库（Phrase Bank）

每季一份，100 句可直接套用的「万能口语句型」，按 **10 大使用场景**分类：疑问调侃 / 表达观点 / 提议邀请 / 安慰缓解 / 抱怨吐槽 / 表白感情 / 职场生活 / 拒绝辩解 / 告别了结 / 幽默讽刺。

### 06-Output · 输出练习

学习成果的对外输出，如小红书图文文案与配套渲染脚本，用于检验与巩固所学。

## 🔁 每日 / 每周流程

1. **精看一集剧** → 笔记写入 `01-Show/`
2. **提炼生词、句型、语法** → 链接到 `02-Vocabulary/`、`04-Phrases/`、`03-Grammar/`
3. **每周日做一次输出练习** → `06-Output/`

新想法随手记进 `00-Inbox/Inbox.md`，每周整理归位。
